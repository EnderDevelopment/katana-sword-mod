# Katana Sword Mod

Adds a unique katana sword with special effects to Minecraft.

## Features

- Adds a katana sword with unique properties
- Special effects when hitting cows, pigs, and zombies
- Visual and sound effects when the sword breaks

## Requirements

- Minecraft 1.16.5 or 1.17
- Forge

## Installation

1. Download the mod file.
2. Place the mod file in your Minecraft mods folder.
3. Launch Minecraft with Forge.

## Usage

1. Craft or obtain the katana sword.
2. Use the sword to hit cows, pigs, and zombies to see the special effects.

## Configuration

No additional configuration is required.
